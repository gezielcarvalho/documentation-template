# Architecture decision records

Create an ADR only for a decision that needs durable technical context. Keep it
short and immutable after acceptance.

```text
# ADR-001: <decision title>

## Status
Proposed | Accepted | Superseded

## Context
What constraint or trade-off requires a decision?

## Decision
What was chosen?

## Consequences
What becomes easier, harder, riskier, or deferred?
```
